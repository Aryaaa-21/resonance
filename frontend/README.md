# RESONANCE — Web Frontend

This directory contains the Next.js React frontend user interface, including the interactive protocol console, 3D verification globe, and wallet integrations.

## Features & Routes
- `/` — Interactive landing page & protocol introduction.
- `/dashboard` — Network verification activity overview.
- `/events` — Real-world verification event explorer & submissions.
- `/witnesses` — Witness node registry and telemetry details.
- `/challenges` — Dispute challenge oversight and resolution.
- `/staking` — Collateral staking dashboard.
- `/network` — Global node telemetry & 3D visualizer.

## Getting Started
```bash
# Install dependencies
npm install

# Start frontend dev server (Port 3000)
npm run dev
```
